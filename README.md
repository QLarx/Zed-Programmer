# Z Programmer

Готовый статический сайт на HTML, CSS и JavaScript. Сервер и сборка не нужны.

## Запуск

1. Распакуйте ZIP в отдельную папку.
2. Откройте `index.html` в браузере.
3. Перейдите в «Библиотека», чтобы искать, фильтровать и копировать скрипты.

Для максимально надёжной работы буфера обмена можно запустить сайт через локальный сервер. Если установлен Python, откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Как добавлять скрипты

Откройте `data/scripts.js`. Внутри `window.ZP_SCRIPTS` находится массив объектов. Добавьте новый объект через запятую между элементами:

```js
{
  id: "js-007",                 // уникальный ID
  title: "Название скрипта",
  language: "JavaScript",
  category: "Утилиты",
  description: "Коротко опишите, что делает этот код.",
  featured: false,              // true — показать на главной
  code: `console.log("Привет!");`
}
```

### Важные правила

- `id` должен быть уникальным.
- `title`, `language`, `category`, `description` и `code` должны быть заполнены.
- Внутри `code` удобно использовать обратные кавычки: `` `...` ``. Если сам код содержит обратную кавычку, экранируйте её обратным слешем или используйте другой способ записи строки.
- Название категории автоматически появится в фильтрах.
- Для показа примера на главной странице установите `featured: true`.
- После сохранения обновите страницу браузера.

## Структура

```text
Z_Programmer/
├── index.html          # Главная страница
├── library.html        # Библиотека скриптов
├── favicon.svg         # Иконка вкладки
├── css/
│   └── style.css       # Стили и адаптивная вёрстка
├── js/
│   ├── main.js         # Логика главной страницы
│   └── library.js      # Поиск, фильтры, сортировка и копирование
└── data/
    └── scripts.js      # Каталог скриптов — редактируйте этот файл
```

## Возможности

- Адаптивная вёрстка для компьютеров и телефонов.
- Поиск по названию, языку, категории, описанию и коду.
- Фильтр категорий и сортировка.
- Копирование кода в буфер обмена.
- Быстрый переход к поиску: `Ctrl+K` или `⌘K`.
- Каталог легко расширять без изменения логики сайта.

## Примечание

Это статический сайт: админ-панели и базы данных нет. Скрипты добавляются редактированием `data/scripts.js`. Шрифт загружается из Google Fonts; при отсутствии интернета используются системные запасные шрифты.
